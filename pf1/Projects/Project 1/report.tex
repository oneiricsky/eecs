\section{Problem Statement}
I was hired as head chef at a restaurant. 
I need to create a program that allows me to scale American recipes
to metric measurements.
First, the program should ask how many the original recipe makes. 
The program should take the amount of servings I need to make. 
Then, it should ask me the pricing of the ingredients in USD. 
After, we should calculate the cost of each serving, first in USD, then in EUR. 
Finally, we can tell how many times we must multiply each ingredient in order to properly scale our recipe.

\section{Design}
I/O is handled via \texttt{std::cin} \& \texttt{std::cout}. While not required, I still handled invalid input via checking \texttt{std::cin} error flag for its \texttt{failbit}: \texttt{validateInput()}. This function wraps \texttt{std::cin} \& \texttt{std::cout}. This works because C++ sets the failbit whenever the input type doesn't fit the destination type (e.g, trying to store a \texttt{std::string} into a \texttt{float} via \texttt{std::cin}).
